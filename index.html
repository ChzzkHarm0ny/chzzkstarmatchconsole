📖 치치직 스타크래프트 중계 콘솔 사용 가이드

본 콘솔은 스타크래프트 방송 중계 시 실시간 스코어보드, 매치리스트, 선수 소개(VS) 화면을 OBS에 송출할 수 있는 웹 기반 중계 제어 시스템입니다.

📊 구글 스프레드시트 DB 복사 / 데이터 작성 / Apps Script 연동 4단계

1단계: DB용 구글 시트 사본 만들기

[⚙️ 3. 기본 설정 및 링크] 탭으로 이동한 후 [📋 DB용 구글시트 초기버전 만들기] 버튼을 누릅니다. 구글 로그인 후 '사본 만들기'를 눌러 내 구글 드라이브에 전용 시트를 생성합니다.

2단계: 시트 내용 채우기 (선수 및 맵 데이터)

  • Players 시트: `선수명`, `종족(프로토스/테란/저그)`, `이미지 URL` 항목을 입력합니다. 선수명은 오버레이에 4글자까지 최적으로 표시되니 가급적 4글자 이내로 등록해 주세요.
  • Maps 시트: `맵 이름`, `맵 이미지 URL` 항목을 입력합니다. 매치리스트 오버레이 칸이 좁으므로, 맵 이름 입력 시 '폴리포이드' 대신 '폴리'처럼 2~3글자 약칭으로 직접 입력해 주시면 예쁘게 출력됩니다.

3단계: Google Apps Script 웹 앱 배포

  1. 구글 시트 상단 메뉴 [확장 프로그램] ▶ [Apps Script]를 실행합니다.
  2. 우측 상단 [배포] ▶ [새 배포]를 누르고 유형을 [웹 앱]으로 선택합니다.
  3. 액세스 권한이 있는 사용자를 '모든 사용자(Anyone)'로 변경 후 배포합니다.
  4. 완료 후 생성된 **웹 앱 URL (`https://script.google.com/macros/s/.../exec`)**을 복사합니다.

4단계: 콘솔에 배포 URL 연동

콘솔의 [⚙️ 3. 기본 설정 및 링크] 탭 하단 '내 구글 스프레드시트 연동 설정'에 복사한 웹 앱 URL을 붙여넣고 [URL 저장]을 누르면 시트 데이터가 콘솔로 바로 동기화됩니다.

👥 1. 선수 및 맵 선택 탭

  • 참가 선수 체크: 시트에서 불러온 선수 중 오늘 출전할 인원을 체크합니다.
  • 팀 배치: 선수 카드를 클릭하여 1팀과 2팀 소속을 배정합니다.
  • 맵 풀 지정: 이번 경기에 사용할 맵을 지정하고 저장합니다.

⚔️ 2. 중계 대시보드 탭

  • 세트 대진 작성: 세트별 매치(1v1, 2v2 등) 형태, 선수, 맵을 매칭하고 [대진 반영]을 누릅니다.
  • 자동 스코어 & 선수 연동: [대진 반영]을 하거나 VS 매치업에서 경기를 고르면 스코어보드 입력창에 선수와 공지가 자동으로 채워집니다.
  • VS 매치업 송출: 선수 소개 화면에 표시할 경기를 고르고 송출합니다.

🎥 OBS Studio 오버레이 연동 방법

  1. [중계 대시보드] 탭에서 오버레이(매치리스트 / 스코어보드 / VS화면)의 [링크 복사]를 누릅니다.
  2. OBS 소스 목록에서 [+] ▶ [브라우저]를 추가합니다.
  3. URL 입력란에 복사한 링크를 붙여넣고 해상도를 맞춥니다 (미니맵 스코어보드: 320x300 권장).
