📖 치치직 스타크래프트 중계 콘솔 사용 가이드

본 콘솔은 스타크래프트 내전 및 방송 중계 시 실시간 스코어보드, 매치리스트, 선수 소개(VS) 화면을 송출할 수 있는 웹 기반 중계 제어 시스템입니다.

1단계: 구글 시트 DB 생성 및 작성 방법

  • 시트 사본 생성: [⚙️ 3. 기본 설정] 탭에서 [📋 DB용 구글시트 초기버전 만들기] 버튼을 눌러 본인 계정에 선수/맵 데이터 시트 사본을 생성합니다.
  • 시트 내용 채우기 (`players` 및 `maps` 탭):
    • 선수(`players`): 선수의 이름, 종족(프로토스/테란/저그), 이미지 주소(`img`) 칸을 채웁니다.
    • 맵(`maps`): 맵 이름과 맵 이미지 주소(`url`) 칸을 채웁니다.
    • 💡 중요 (이미지 등록 방법): 선수 프로필 사진이나 맵 이미지는 컴퓨터에 있는 파일을 바로 넣을 수 없습니다. 이미지를 웹(블로그, 이미지 호스팅, GitHub 등)에 업로드한 뒤 생성된 이미지 주소(URL)를 시트의 이미지 칸에 입력해야 콘솔과 오버레이에 정상적으로 출력됩니다.

2단계: 구글 시트 웹 앱 배포 및 연동

  • Apps Script 열기: 생성된 구글 시트 상단 메뉴에서 [확장 프로그램] ➔ [Apps Script]를 클릭합니다.
  • 웹 앱 배포하기:
    1. 우측 상단의 [배포] ➔ [새 배포]를 클릭합니다.
    2. 왼쪽 상단 톱니바퀴(유형 선택) 아이콘을 눌러 [웹 앱]을 선택합니다.
    3. 설명은 간단히 적고, 액세스 권한 있는 사용자를 반드시 [모든 사용자(Anyone)]로 설정한 뒤 하단의 [배포] 버튼을 누릅니다. (권한 검토 창이 뜨면 본인 계정 선택 ➔ [고급] ➔ [안전하지 않음으로 이동]을 눌러 허용)
  • URL 복사 및 저장: 배포 완료 후 발급되는 [웹 앱 URL](끝이 `/exec`로 끝나는 주소)을 복사합니다. 콘솔의 [⚙️ 3. 기본 설정] 탭으로 돌아와 '내 구글 스프레드시트 연동 설정' 칸에 붙여넣고 [URL 저장]을 누릅니다.

3단계: 선수 및 맵 풀 구성

  • [👥 1. 선수 및 맵 선택] 탭으로 이동합니다.
  • 프로토스, 테란, 저그 종족별 구획으로 정돈된 선수 목록에서 이번 경기에 참가할 선수를 체크합니다.
  • 하단에서 1팀과 2팀에 소속될 선수를 확인하고 팀 이름을 설정한 뒤 [팀 설정, 참가 선수 및 맵 구성 저장하기] 버튼을 누릅니다.
  • ※ 선수의 종족이 변경될 경우, 연동된 구글 시트의 `players` 탭에서 수정하시면 실시간으로 반영됩니다.

4단계: 세트별 대진 설정 및 중계 진행

  • [⚔️ 2. 중계 대시보드] 탭으로 이동합니다.
  • 각 세트별(1세트, 2세트 등) 상세 대진 표에서 매치 형태(1v1~4v4)와 선수를 지정합니다.
  • 현재 진행 중인 경기에 동그란 선택 버튼을 체크하고, 승리 팀에 '승'을 체크한 뒤 [대진 및 현재 경기 반영하기]를 누르면 스코어가 자동으로 집계됩니다.
  • 미니맵 스코어보드 하단에 노출될 선수 위치(예: 9, 3)를 콘솔 하단 입력란에 직접 적고 [위치 즉시 반영]을 누르면 오버레이에 즉시 반영됩니다.

5단계: OBS 스튜디오 오버레이 링크 연동

  • 중계 대시보드 상단 및 각 제어부에 있는 [링크 복사] 버튼을 이용해 URL을 복사합니다.
  • OBS 스튜디오에서 '브라우저 소스'를 추가하고 복사한 URL을 붙여넣어 화면에 배치합니다.
  • 배경은 투명하게 처리되어 있으므로 뒤쪽 중계 화면 위에 얹어서 바로 사용하실 수 있습니다.
